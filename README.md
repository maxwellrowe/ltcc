# Lake Tahoe Community College — Modern Campus CMS

This repository contains the Modern Campus CMS build for Lake Tahoe Community College (LTCC).

It serves as the version-controlled workspace for developing and maintaining the college’s website, including site pages, code, and supporting resources used in the Modern Campus CMS build.

## Repository assets

Images are tracked in this repository. PDFs, video, and audio files are excluded from Git and should be managed separately in Modern Campus CMS or the appropriate asset storage. Local copies of these files are ignored by Git.

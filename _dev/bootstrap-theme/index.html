Buttons and badges

Buttons use semibold (600) text and a 3px radius in every size. Padding (vertical / horizontal): small .375rem .9375rem, default .5rem 1.25rem, large .75rem 1.875rem. Outline primary uses blue-800 text and a bright blue border; outline secondary uses green-900 text and a bright green border. Hover and active states use the bright fill and dark border/text.

Light buttons use green-100 with green-900 text, changing to bright green on hover and when active.

Solid primary buttons use a green-900 hover border; solid secondary buttons use a blue-900 hover border.

Scroll animations

Add one animation class to an element. It reveals once when it reaches 80px above the bottom of the viewport, over 600 milliseconds. Scroll down to see these examples; reload the page to replay them.

ClassEffect
anim-scroll-fadeFade in without movement.
anim-scroll-fade-upFade in while moving upward 24px.
anim-scroll-slide-leftUncover from the right edge toward the left, without fading or moving.
anim-scroll-slide-rightUncover from the left edge toward the right, without fading or moving.

Delay utilities

Add anim-delay-200, anim-delay-500, or any nonnegative whole number of milliseconds. The delay starts when the element reaches that 80px trigger offset. Use one delay class per element; without one, animation starts immediately.

<div class="anim-scroll-fade-up anim-delay-200">Your content</div>
<div class="anim-scroll-slide-left anim-delay-500">Your content</div>

Reduced-motion preferences skip all effects and delays. Offscreen elements wait at opacity zero after Motion initializes, only when the html element does not have no-js. Content already visible at initialization stays visible without animating, preventing a loading flash. Content remains visible without JavaScript. Delay classes are read by JavaScript and need no additional CSS. Directional reveals use clip-path, keeping full layout width so text does not reflow. Apply animation to a wrapper if the content already uses transforms or clip-path. For dynamically inserted content, call LTCC.animations.init(container).
